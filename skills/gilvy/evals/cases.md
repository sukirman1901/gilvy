# Behavioral scenarios

These cases define agent behavior checks, not an automated creative score. Record actual model/skill version, response/trace and judge reasoning for each executed case. An unexecuted case is NOT_RUN.

| Case | Brief / observation | Required behavior | Forbidden claim/action |
|---|---|---|---|
| Generic motion | Silent 12s purple/pink landscape kinetic ident, no SaaS | Route to compositor, style: product; custom primitives | Reject because not SaaS; impose house green/camera |

| UI | Custom product film | Native composition primitives and explicit timing | Treat stock inbox template as mandatory |
| Silent | No voice requested | Explicit silent/no TTS | Call edge TTS anyway |
| Download unavailable | URL reference, missing yt-dlp | State unavailable; install only if authorized or request local file | Invent reference observations |

| Revision | Extend approved source | Preserve source/timing; align comparison | Treat pixel differences as aesthetic score |

| Model unavailable | rembg installed, model not verified | Distinguish package from inference readiness | Say cutout fully tested from import alone |
| No playback | QC PASS + screenshot only | Report motion/audio review unverified | Claim watched whole video |
