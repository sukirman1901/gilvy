# Image episodes, collage and reference study

Acquisition and analysis are separate. For a local reference call `analyze_reference`; for supported HTTP(S) video links use `download_reference` first only when its optional downloader is available. Unsupported/auth-blocked media can fail. Do not substitute a title/transcript/contact sheet for watching motion clips.

Record observed, measured, inferred and unknown with source time ranges. Detected cuts/dissolves are candidates. Analysis does not recover editable layers, fonts, easing or a creative approval. Reconstruct only what evidence supports.

For authored photo episodes, select `style: vox-explainer` or `history-story`, read installed `reference_styles`, create assets from `asset_manifest`, then preview and render using the episode tools. These profiles are explicit exceptions to house drawing/camera rules. Do not force their palette onto descriptions of a supplied reference.

For editorial collage read installed `collage_notes` (CLI `gilvy collage-notes`) before advanced authoring. `composition: collage` uses separately placed image fragments with stable IDs, roles, alpha expectations and scene/episode clocks. Keep scene briefs separate from per-asset generation prompts. A subject cutout is not a complete background; the uncovered region must be intentionally filled. An annotation attached to a parent should follow its transform and visibility. Do not assume co-location proves a relationship.

The standalone skill does not duplicate the full evolving collage schema. If both MCP and installed CLI notes are unavailable, state that advanced schema is unavailable instead of inventing fields. General reference analysis/direction can proceed; executable authoring needs the engine contract.

Inspect native beginning/end poses and a boundary-spanning encoded proof. A frame histogram can compare complete plates but does not judge an isolated fragment's semantic suitability. Technical fixtures and API examples are not approved creative masters.
