# Earlier accepted house studies

These sources preserve the earlier minimalist house work. They are separate
from API examples and test fixtures so an agent cannot mistake every runnable
file for an approved creative master. Their original scene code is preserved.

| Study | Scope |
| --- | --- |
| `bojonegoro/episode.yaml` | Earlier 41-second dot/line narrative about work and regional oil revenue. Read `bojonegoro/SOURCES.md`: the data is dated and must be checked before new publication. Its worker count and source code are also exercised by regression tests. |
| `reflection.yaml`, `reflection_scene.py` | Earlier trail-to-barrier metaphor about continuing in the wrong direction. The retained strokes connect the two beats. |

These studies concern the house style only. They do not establish an approved
Vox collage, photographic cutout, or SaaS UI standard. Transfer object identity,
meaning, unit discipline, and continuity; do not copy their subject or force a
new brief into the same dots, rings, or caption arrangement.
